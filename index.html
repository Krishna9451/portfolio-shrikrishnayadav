03 · projects
Three-Tier Architecture on AWS
cloud infra

Designed and deployed a highly-available three-tier application architecture on AWS, focused on secure networking and resilient compute rather than just "getting it running."

traffic in via ALB → app tier (SSM-managed, no SSH) → Aurora · outbound-only via NAT
  • Built a custom VPC with public and private subnets, using an Internet Gateway and NAT Gateway to control inbound/outbound traffic flow.
  • Fronted the app tier with an Application Load Balancer connected to an Auto Scaling Group for elasticity and availability.
  • Accessed backend instances through AWS Systems Manager (SSM) instead of SSH, removing the need for open inbound ports or key-based access.
  • Connected the app tier to a managed Aurora PostgreSQL database in the private subnet.
